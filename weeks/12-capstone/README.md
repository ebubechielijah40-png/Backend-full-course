# Week 12 — Independent Capstone

## What students already know

Every outcome in `../../LEARNING_OUTCOMES.md` — modeling, SQL, the ORM,
REST APIs, authentication, testing, security, deployment, and Git.

## What they need to learn this week

Nothing new. This week applies everything already taught, under Stage 3
(independent) AI usage rules (see `../../AI_USAGE_POLICY.md`).

## What they will build

The **Capstone Project** — see `../../capstone/README.md` for the full
specification: an original backend application built from a written
spec, largely unassisted.

## Concepts necessary to build it

All of Weeks 1–11.

## What should NOT be taught yet

Nothing is introduced this week — introducing new material now would
undermine the point of measuring independent ability.

## What the three sessions accomplish

1. Reading the capstone spec; planning models and API.
2. Independent build time.
3. Independent build time, testing, and deployment.

## What the project accomplishes

Serves as the course's final, comprehensive assessment (see
`../../ASSESSMENT.md`) — the actual target outcome of the whole course.

## Practical skill at week's end

Demonstrated, independent ability to build and ship a backend
application from a specification.
