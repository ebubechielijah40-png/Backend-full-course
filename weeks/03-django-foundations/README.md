# Week 3 — Django Foundations

## What students already know

HTTP request/response fundamentals, methods, status codes (Week 2), and
organized Python (Week 1).

## What they need to learn this week

- Django's project vs. app structure and how to create both.
- URL routing: mapping a path to a view.
- View functions and how they return responses.
- Templates: rendering dynamic HTML with variables.
- The settings module and static files at an introductory level.

## What they will build

A **Personal Portfolio / Blog site**: a multi-page Django site with
routed views and templated pages (static content — no database models
introduced yet).

## Concepts necessary to build it

Week 2's request/response model (a Django view is "a function that takes
a request and returns a response," which students already understand).

## What should NOT be taught yet

- Database models, migrations, or the admin site (Week 4) — keep this
  week's cognitive load to routing/views/templates only.
- The Django ORM or any database concept.
- REST APIs.

## What the three sessions accomplish

1. Project/app structure, URL routing, first views.
2. Templates and dynamic HTML.
3. Settings, static files, and assembling the full multi-page site.

## What the project accomplishes

Gives students a real, running Django site they built page by page,
without yet needing to understand a database.

## Practical skill at week's end

Can create a Django project from scratch and serve multiple routed,
templated pages.
